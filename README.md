- cobol/01_structure.cbl: 基本構造、WORKING-STORAGE、段落
- cobol/02_if_evaluate.cbl: IF / EVALUATE
- cobol/03_perform.cbl: PERFORM / ループ
- cobol/04_file_io.cbl: SEQファイル入出力（READ/WRITE/EOF）
- cobol/05_string_inspect.cbl: STRING/UNSTRING/INSPECT
- cobol/06_tables_occurs.cbl: OCCURS / SEARCH
- cobol/07_subprogram_call.cbl: CALL / USING
- cobol/08_subprogram.cbl: LINKAGE SECTION / USING

## JCL（サンプル）
- jcl/compile.jcl: コンパイル→リンク→実行
- jcl/compare.jcl: IEBCOMPRでファイル比較
